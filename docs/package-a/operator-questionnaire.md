## Why this version is different

We have now read through your DaySmart Dash account, view only: settings, programs, the calendar, the register, roles, one family record and one team. So most questions below start from what Dash already shows and ask you to confirm, correct or choose. Very few are blank-page questions.

## How to answer

- Each row has one question. The third column is what we found in Dash. The fourth says the kind of answer we need.
- "Same as today" is a complete answer wherever the third column describes how you work now.
- If nobody knows, write "don't know" and who might. An unanswered row stays open; we never treat silence as "not needed".
- Write who answered and the date at the top of each section. Prices, tax, refund amounts and legal wording must come from you; we will not invent them.
- Sections A and B have the longest lead times. Please start them first. The rest can be answered in any order and by different people.

Suggested owners: owner/general manager (A, B, N, P), operations manager (C, H, I), program directors (D, E, F, J), accounting (G, L), whoever sends the emails (K), whoever knows the old data (M).
